Data and Code Availability

All sequencing data analyzed in this study are publicly available through the curatedMetagenomicData Bioconductor package (https://bioconductor.org/packages/release/data/experiment/html/curatedMetagenomicData.html; doi:10.18129/B9.bioc.curatedMetagenomicData). The ten cohorts used are FengQ_2015, GuptaA_2019, ThomasAM_2018a, ThomasAM_2018b, ThomasAM_2019_c, VogtmannE_2016, WirbelJ_2018, YachidaS_2019, YuJ_2015, and ZellerG_2014. Original raw-read accession numbers for each cohort are recorded in the curatedMetagenomicData metadata table. The HanniganGD_2017 cohort was pre-specified as excluded prior to classification based on sequencing-depth and feature-sparsity criteria; the exclusion rule is documented in the Methods.

All analysis code, pre-processed MetaPhlAn species and HUMAnN unstratified pathway feature matrices, per-sample classifier predictions, and derived result tables (Supplementary Tables S1-S10) are publicly available at https://github.com/alejandro-publius/crc-metagenomics under the MIT license. The repository includes the end-to-end analysis pipeline (preprocessing, LODO cross-validation, joint species + pathway models, adenoma analyses, DeLong tests, bootstrap confidence intervals, SHAP, and sensitivity analyses), a step-by-step reproduction protocol (REPRODUCING.md), pinned dependency versions (requirements.lock), and an automated verification script (scripts/verify_results.py) that runs 49 checks confirming every reported number matches the deposited result files. A versioned Zenodo snapshot of the repository at the submission commit will be archived and its DOI added here upon acceptance of this preprint.
